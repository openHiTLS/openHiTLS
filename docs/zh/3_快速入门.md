# openHiTLS快速入门

欢迎学习openHiTLS教程。此教程将会指导您如何安装、集成和使用openHiTLS。

## 什么是openHiTLS

openHiTLS是一款构建密码学安全能力的C/C++库，提供符合公开标准的密码学算法、TLS协议栈。

## 安装openHiTLS

1. 下载相关代码

   ```
   git clone https://gitcode.com/openhitls/openhitls.git
   ```

   > - GitHub仓库（https://github.com/openHiTLS/openHiTLS）：与gitcode仓库双向同步；
   > - gitee仓库（https://gitee.com/openhitls/openhitls.git）：由GitHub单向同步，内容可能滞后。

2. 构建安装，在openHiTLS根路径下执行以下命令：

   ```
   mkdir build
   cd build
   cmake ..
   make && make install
   ```

   安装说明：

   - 默认安装前缀为`/usr/local`：头文件安装至`/usr/local/include/hitls/`下的`bsl`、`crypto`、`tls`、`pki`、`auth`子目录，库文件安装至`/usr/local/lib`。
   - 非 root 用户执行`make install`需加`sudo`，或在配置时通过`-DCMAKE_INSTALL_PREFIX=<目录>`指定自定义安装前缀（后续步骤中的头文件与库路径需相应调整）。

## 在您的C/C++项目中集成openHiTLS

1. 按照openHiTLS的[API参考](./5_开发指南/3_API参考.md)，在您的项目代码中调用openHiTLS提供的接口。
2. 将openHiTLS的头文件和库路径加入到您的项目依赖中，以gcc编译器为例：

   头文件按模块分层安装，若代码同时引用多个模块的头文件（如下例引用了`crypto`与`bsl`两个模块），需为每个模块指定`-I`；引用`tls`、`pki`、`auth`模块头文件时同理追加对应路径。使用`-L`指定库文件路径：

   ```
   gcc application.c -o app \
     -lhitls_crypto -lhitls_bsl \
     -I /usr/local/include/hitls/crypto -I /usr/local/include/hitls/bsl \
     -L /usr/local/lib
   ```

3. 运行前置说明：链接openHiTLS动态库的程序，安装后首次运行前需确保动态库可被加载，否则报`libhitls_crypto.so: cannot open shared object file`。

   - Linux：执行`sudo ldconfig`刷新动态库缓存；
   - macOS：执行`export DYLD_LIBRARY_PATH=/usr/local/lib`，或在编译命令中追加`-Wl,-rpath,/usr/local/lib`。

## 开始使用openHiTLS

以下示例使用SM3摘要接口计算消息摘要，可作为验证环境是否就绪的最小用例（其他算法的完整示例见`testcode/demo/`）。将代码保存为`application.c`：

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include "crypt_eal_md.h" // 摘要接口头文件
#include "bsl_sal.h"
#include "bsl_err.h"
#include "crypt_algid.h" // 算法id列表
#include "crypt_errno.h" // 错误码列表

void *StdMalloc(uint32_t len) {
    return malloc((size_t)len);
}

int main(void)
{
    const uint8_t data[] = "hello openHiTLS";
    uint8_t digest[64] = {0};
    uint32_t len = sizeof(digest);
    int32_t ret;

    // 初始化错误码模块,并注册内存回调
    BSL_ERR_Init();
    BSL_SAL_CallBack_Ctrl(BSL_SAL_MEM_MALLOC, StdMalloc);
    BSL_SAL_CallBack_Ctrl(BSL_SAL_MEM_FREE, free);

    // 创建SM3摘要上下文
    CRYPT_EAL_MdCtx *ctx = CRYPT_EAL_MdNewCtx(CRYPT_MD_SM3);
    if (ctx == NULL) {
        printf("create md ctx failed\n");
        return 1;
    }

    // 计算摘要:Init -> Update -> Final
    ret = CRYPT_EAL_MdInit(ctx);
    if (ret != CRYPT_SUCCESS) {
        printf("init failed, error code is %x\n", ret);
        goto EXIT;
    }
    ret = CRYPT_EAL_MdUpdate(ctx, data, sizeof(data) - 1);
    if (ret != CRYPT_SUCCESS) {
        printf("update failed, error code is %x\n", ret);
        goto EXIT;
    }
    ret = CRYPT_EAL_MdFinal(ctx, digest, &len);
    if (ret != CRYPT_SUCCESS) {
        printf("final failed, error code is %x\n", ret);
        goto EXIT;
    }

    printf("sm3(\"%s\") = ", data);
    for (uint32_t i = 0; i < len; i++) {
        printf("%02x", digest[i]);
    }
    printf("\n");

EXIT:
    CRYPT_EAL_MdFreeCtx(ctx);
    BSL_ERR_DeInit();
    return ret;
}
```

使用上一节的编译命令构建并运行：

```
gcc application.c -o app \
  -lhitls_crypto -lhitls_bsl \
  -I /usr/local/include/hitls/crypto -I /usr/local/include/hitls/bsl \
  -L /usr/local/lib
sudo ldconfig
./app
```

预期输出（若输出如下，说明环境已就绪）：

```
sm3("hello openHiTLS") = 76c94d0f012e2a19a5cb8f41e8fcab0e73a4db5934f75cd81570bd2e6703d06d
```
